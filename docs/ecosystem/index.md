
# Ecosystem

This chapter describes projects within the Fusio ecosystem.

* __[Framework](./framework)__
  > Starter repository to use Fusio as a framework.

* __[Plant](./plant)__
  > Server panel to easily self-host Fusio and other apps on your own infrastructure with one click.

* __[Grid](./grid)__
  > Connect to any MySQL, PostgreSQL, or SQLite database to automatically expose your table schemas as secure, type-safe REST endpoints.

* __[Pulse](./pulse)__
  > Self-hosted notification gateway to send chat, email, push and SMS messages through a single API.
